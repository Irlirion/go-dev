# Go homework

Репозиторий содержит заготовки домашних заданий по Go к урокам 2 и 3 и общей дополнительной самостоятельной работы.

## Структура

- `hm2/` — пять независимых задач с описаниями, стартовым кодом и автотестами. У каждой задачи свой `go.mod`.
- `hm3/` — три задачи на указатели, срезы и `map` с описаниями, стартовым кодом и автотестами. Общий `go.mod` находится в `hm3/` (Go 1.22 или новее).
- `sr1/` — самостоятельная работа «Анализатор продаж» по темам уроков 1–3. Описание находится в `sr1/README.md`, заготовка и автотесты — в отдельном Go-модуле `sr1/starter/` (Go 1.22 или новее). Домашнего задания к уроку 4 нет.
- `Makefile` — общие команды для всех задач в `hm2/` или для выбранного Go-модуля.

Решения выполняются самостоятельно в исходных файлах задач. Не меняйте сигнатуры функций и автотесты.

## CI

GitHub Actions запускает `make test` для всех модулей `hm2/` при push в `main`, для pull request и вручную. Проверка выполняется на Go 1.22 и Go 1.27.

## Команды

Из корня репозитория:

```sh
make help
make test
make fmt
make vet
make build
make clean
```

По умолчанию команды выполняются во всех модулях `hm2/`. Чтобы выбрать один каталог, передайте путь через `DIR`:

```sh
make test DIR=hm2/01_order_total
make fmt DIR=hm2/01_order_total
make vet DIR=hm2/01_order_total
make build DIR=hm2/01_order_total
make clean DIR=hm2/01_order_total
```

Путь указывается относительно корня репозитория и должен вести к каталогу с `go.mod`. Для других Go-проектов можно указать их каталог, например `make test DIR=../my-go-project`.

### Домашнее задание 3

Начните с [описания hm3](hm3/README.md). Решения пишите в `main.go` соответствующих задач, сохраняя сигнатуры функций и выданные тесты.

Команды для всего задания из корня репозитория:

```sh
make test DIR=hm3
make fmt DIR=hm3
make vet DIR=hm3
make build DIR=hm3
```

Чтобы запустить тесты только одной задачи:

```sh
cd hm3
go test ./01-pointers
go test ./02-slices
go test ./03-maps
```

Пока заготовки не реализованы, тесты могут падать. Команда `make test` без `DIR` и CI по-прежнему проверяют только `hm2/`.

### Самостоятельная работа 1

Начните с [описания СР-1](sr1/README.md). Реализуйте `AnalyzeSales` в `sr1/starter/analytics.go`, не меняя сигнатуру, типы и выданные тесты. Перед сдачей дополните `sr1/starter/README.md` описанием алгоритма и его сложности.

Команды из корня репозитория:

```sh
make test DIR=sr1/starter
make fmt DIR=sr1/starter
make vet DIR=sr1/starter
make build DIR=sr1/starter
```

Команда `make test` без `DIR` и CI по-прежнему проверяют только `hm2/`.

## Pre-commit

Pre-commit автоматически форматирует изменённые Go-файлы перед коммитом:

```sh
brew install pre-commit
pre-commit install
```

Тесты автоматически не запускаются.
