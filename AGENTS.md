# Инструкции для работы с репозиторием

## Назначение

Это учебный репозиторий для домашних заданий по Go. Пользователь решает задания самостоятельно. Помогай готовить и поддерживать среду, разбирать требования и давать подсказки; не пиши решения за пользователя, если он явно об этом не попросил.

## Структура заданий

- Размещай домашние задания по папкам `hm1/`, `hm2/` и далее.
- Внутри папки задания сохраняй выданные описания, заготовки и автотесты.
- Для `hm2/` каждая задача является отдельным Go-модулем со своим `go.mod`.
- Не меняй сигнатуры функций и выданные тесты. Не подменяй заготовки готовыми решениями.
- Не создавай `hm1/`, пока пользователь не предоставит материалы для этого задания.

## Работа с Go и Makefile

- Модули `hm2` рассчитаны на Go 1.22 и новее. Локальная среда пользователя: Go 1.27.1, darwin/arm64.
- Из корня репозитория используй Makefile. Без `DIR` команды применяются ко всем модулям `hm2`; для одного модуля указывай, например, `make test DIR=hm2/01_order_total`.
- `DIR` задаётся относительно корня репозитория и должен указывать на каталог с `go.mod`.
- Не запускай тесты без просьбы пользователя.

## Границы репозитория

- Корневой README должен описывать актуальную структуру и команды.
- Проект `llm-gateway` находится отдельно, рядом с этим репозиторием; не переносить его обратно и не включать в изменения этого репозитория без просьбы пользователя.
