## Алгоритм

Продажи обрабатываются за один проход. Отменённые записи пропускаются
до валидации, некорректные — подсчитываются и исключаются из расчётов.

Для корректных продаж накапливаются общая выручка, количество проданных
единиц, выручка по категориям и количество единиц каждого товара.
После обновления количества товара проверяется, стал ли он лидером.
При равенстве выбирается лексикографически меньшее название.

Исходный срез не изменяется.

## Сложность

Пусть n — число продаж, p — число уникальных корректных товаров,
c — число уникальных корректных категорий.

- Время: O(n), при среднем времени операций с map O(1).
- Дополнительная память: O(p + c).
