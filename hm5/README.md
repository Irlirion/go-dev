# Домашнее задание 5 — ошибки в сервисе уведомлений

[Условия, команды запуска и ответы](homework/README.md).

- `homework/` — решение и исходные автотесты, отдельный модуль Go 1.22.
- `starter/main.go.txt` — исходная заготовка без изменений, сохранена как текст,
  чтобы её незавершённые функции не участвовали в сборке решения.

Используются только стандартная библиотека и темы задания: структуры,
методы, интерфейсы, срезы, error, errors.Is/As, обёртки %w, defer и recover.
